Writing the total value of a digit in a number

The total value of each digit in a number can be obtained as follows:

Example 1

Write the total value of each digit in 478.

In the number 478, the digit 4 has a total value of 400, the digit 7 has a total value of 70, and the digit 8 has a total value of 8.

4 7 8
Ones Tens Hundreds

The total value of 4 is 400.

The total value of 7 is 70.

The total value of 8 is 8.
