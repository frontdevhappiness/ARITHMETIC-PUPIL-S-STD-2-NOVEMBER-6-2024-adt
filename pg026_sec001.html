Recognizing the place value of a digit

Each position in a number carries a place value. The place value is recognized from the right towards the left of the number.

Example 1

Write the place value of each digit in 324.

In the number 324, 3 is in the hundreds place, 2 is in the tens place, and 4 is in the ones place.

3 2 4
Ones Tens Hundreds

Example 2

Write the place value of each digit in 349.

349 = 3 hundreds 4 tens 9 ones
